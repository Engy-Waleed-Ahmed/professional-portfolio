Personal Portfolio Website

A modern and responsive personal portfolio website designed using HTML, CSS, Bootstrap, and JavaScript.

HTML5CSS3Bootstrap 5JavaScript

Overview

This is the portfolio website you are browsing right now. It presents a student's background, skills and projects in one responsive page.

It is a good example of a small static website: no backend, no build tools, and code that is simple enough to explain line by line.

Key Features

Responsive layout

Adapts to phones, tablets and desktops using the Bootstrap grid.

Smooth navigation

Sticky navbar, smooth scrolling and active-link highlighting.

Form validation

Contact form checks required fields and the email format in JavaScript.

Accessibility

Semantic HTML, visible focus states, alt text and reduced-motion support.

What I Practise

  • Building responsive layouts with Bootstrap and custom CSS.
  • Organising CSS with variables and sections.
  • Writing small, readable JavaScript features.
